Purpose and how to read this
This ruleset turns SikhRI's two published project pages, Approach and Methodology, into numbered, checkable rules for rendering Gurbani into English. It is a proof of concept: every rule traces to one of those pages, and nothing is invented.
Rule IDs follow the pattern SECTION-NN (for example TERM-01). Each rule carries a source tag: [A] = Approach page, [M] = Methodology page.

Scope. Covers the English literal translation, the English interpretive transcreation, the supporting annotation fields, and Gurmukhi-to-Roman transcription. Panjabi transcreation follows the same principles but is out of scope for this POC.

The clearest prescriptive rules SikhRI publishes concern word choice: avoid English terms that import outside theology.

3. Workflow and layers of meaning (FLOW)
Work proceeds bottom-up: the word-level annotation drives every rendering above it. Work is organized by Bani (composition), not page by page.
Required order [M]
1. Annotate each word in Gurmukhi: meaning, grammar and etymology (see ANNO).
2. Write the literal translation for each pauri (stanza) or line (see LAYER-01 to 05).
3. Write the interpretive transcreation from the annotation and the literal translation (see LAYER-06 to 10).
4. Add the supporting layers: overview, introduction, commentary, and the historical, musical and poetical dimensions.

Supporting layers [M]
• Overview: a brief glimpse of the larger message of a stanza, Sabad or Bani.
• Introduction: page, rag, author(s), themes and scholarly arguments, drawing on outside sources when needed.
• Commentary: the essence of the Sabad, its contemporary application and nuance, and how it departed from the religious or political ideas of its time.
• Historical, musical and poetical dimensions: context from traditional Sikh sources and South Asian scholarship; the rag's meaning and form; figures of speech and poetic form.
• Footnotes and in-text citations: definitions, pronunciation guidance, context, and supporting references from within the Guru Granth Sahib.
5. Consistency (CONS)
SikhRI explicitly rejects rigid one-to-one consistency, but it also rejects arbitrary inconsistency. The target is reasoned consistency with documented exceptions.
ID
Rule
Level
Source
CONS-01
Default to the English rendering already used for the same or a similar term elsewhere in the project.
SHOULD
[M]
CONS-02
Depart from the default when context requires it. Rigid consistency that ignores context is a misrepresentation.
MUST
[M]
CONS-03
Never vary a rendering without a reason. Each departure from the default needs a recorded justification.
MUST
[M]
CONS-04
Decide, per case, whether an explanatory footnote is needed, weighing the audience's expectations.
SHOULD
[M]
Decision test for a term: use the established rendering, unless this context changes the meaning. If it does, use the context-fit rendering and log why (for example in a footnote or the term log).

7. Transcription (TRAN)
SikhRI uses transcription (sound-based) rather than transliteration (spelling-based), because Gurmukhi is highly phonetic and pronunciation affects meaning. The full character chart is on the Methodology page; the rules below are the ones a reviewer checks.
ID
Rule
Example
Level
TRAN-01
Use transcription, not transliteration. Pronunciation takes precedence over pattern rules.
ਪਰਮਦਭੁਤੰ → parmadbhutaṅ
MUST
TRAN-02
In proper nouns outside line meanings and footnotes, use the common spelling.
Duni Cand → Duni Chand
MUST
TRAN-03
A consonant with no vowel sign carries an implicit "a", except when it is the last letter of a multi-letter word.
ਨਦਰ → nadar
MUST
TRAN-04
A single-letter word keeps its implicit "a".
ਨ → na
MUST
TRAN-05
The implicit "a" may be dropped mid-word where natural pronunciation drops it.
ਦਰਸਨ → darsan
SHOULD
TRAN-06
Mark ਉ or ਇ following a short-"a" consonant with a dieresis.
ਸਉ → saü
MUST
TRAN-07
Vowel signs map to a, ā, i, ī, u, ū, e, ai, o, au.
ਸੂਰਾ → sūrā
MUST
TRAN-08
A ṭippī takes the nasal of the following consonant's row (ṇ, ṅ, ñ, n, m); word-final it defaults to "aṅ".
ਸੰਗਤਿ → saṅgati; ਕਰਮੰ → karmaṅ
MUST
TRAN-09
Write all vowel nasalization as ṁ (ṭippī or bindī).
ਤੂੰ → tūṁ
MUST
TRAN-10
Write visarg as ḥ, preceded by an implicit "a".
ਦ੍ਰਿੜੰਤਣਃ → driṛantaṇaḥ
MUST
TRAN-11
Pronounce a subscript directly after its consonant, with no implicit "a" between them.
—
MUST
TRAN-12
Represent the halant-like sign with the same mark in Roman.
ਜਿਨੑੀ → jin̖ī
MUST
TRAN-13
Word-final ਅ after a vowel marks prolongation.
ਜੀਅ → jīa
MUST
TRAN-14
Transcribe Gurmukhi numerals as Roman digits, unless the number is spelled out in the original.
੧ → 1; ਇਕੁ → iku
MUST
TRAN-15
Farsi-derived letters use their Roman equivalent (ਫ਼ → f, ਜ਼ → z), or an underlined letter where Roman has none.
—
MUST
TRAN-16
Double the letter marked by adhak (only the first letter of a digraph). Adhak does not occur in the Guru Granth Sahib itself.
ਭੱਠੀ → bhaṭṭhī
MUST

9. Reviewer checklist
Run this on every Sabad before release. A failed MUST item blocks publication.
[ ] Every word is annotated with meaning, grammar and etymology (FLOW-01, ANNO)
[ ] Literal translation is in italics and drops no source word or grammatical position (LAYER-01, 02)
[ ] Every added word in the literal translation is in parentheses (LAYER-03)
[ ] Transcreation has no parentheses and does not mirror the source line by line (LAYER-07, 08)
[ ] No "God" or "Lord" anywhere (TERM-01)
[ ] Each Divine attribute matches the one used in the original (TERM-02)
[ ] No "scripture", "canon", "ved" or "shastra" for the Guru Granth Sahib (TERM-04, 05)
[ ] Repeated words in the Sabad are rendered consistently (TERM-08)
[ ] Any departure from an established rendering has a logged reason (CONS-03)
[ ] Transcription follows the TRAN rules; proper nouns use common spellings (TRAN-02)
[ ] Nothing claims to be the definitive or only correct meaning (PRIN-04)
[ ] The humility note is attached (PRIN-03)
