# All Rules Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make all 66 SikhRI seed rules visible and actionable across their authored layers, with the greatest evidence-backed automation the current inputs support.

**Architecture:** Preserve the existing versioned rules and review-only engine. Add layer-aware authored records and structured evidence; run deterministic checks first, then rule-specific model packets. Track rules that cannot run as explicit `not_evaluable` or `not_applicable` results. Keep workflow assessments separate from exact-span text findings.

**Tech Stack:** Next.js 16, TypeScript 7, Zod 4, Drizzle/SQLite, Vitest 5, existing AI SDK and Anthropic adapter.

**Spec:** `docs/superpowers/specs/2026-10-16-all-rules-design.md`

## Global Constraints

- Keep SikhRI rule text verbatim; decisions belong in `_docs/rules/resolve.py` and the generated JSON.
- Eko never writes English translations or Gurmukhi. BaniDB Gurmukhi is NFC and read-only.
- Every text finding must cite a current exact submitted span and valid rule/reference IDs.
- Every human decision and waiver has a typed name and written reason.
- Preserve current transcreation drafts and publication history; no silent database reset.
- Missing evidence is never a pass. ANNO-07 is not evaluable when BaniDB lacks a required form.
- Use Node 22 and pnpm 11.25.0. Keep Mac and Windows development paths portable.

## Review Focus

- A saved literal and transcreation covering the same source line must coexist and reload independently.
- Editing one layer must invalidate dependent checks without clearing unrelated findings.
- A model packet lacking a required source or reference must say `not_evaluable`, not pass or fabricate a citation.
- A transcription exception governed by pronunciation must not become a mechanical error.
- A process assertion without a recorded event and reason must not count as compliance.
